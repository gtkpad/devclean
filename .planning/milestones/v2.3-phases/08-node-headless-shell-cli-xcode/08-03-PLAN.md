    2. In `internal/cleaner/xcode/xcode.go`:
       - Implement `checkProcessStatus(ctx context.Context, exec cleaner.CommandExecutor, processName string) (running bool, uncertain bool)` per D-12:
         - Invoke `out, err := exec.Output(ctx, "pgrep", "-x", processName)`.
         - If `err == nil && len(strings.TrimSpace(string(out))) > 0`: return `true, false` (definitely running).
         - Check if `err` implements `interface{ ExitCode() int }` via `errors.As(err, &exitErr)`. If `exitErr.ExitCode() == 1`: return `false, false` (definitely not running).

       - In `c.Scan()`:
         - Evaluate `xcodeRunning, xcodeUncertain := checkProcessStatus(ctx, c.exec, "Xcode")`.
         - Evaluate `simRunning, simUncertain := checkProcessStatus(ctx, c.exec, "Simulator")`.
         - Compute `xcodeBlocked := xcodeRunning || xcodeUncertain`.
         - Compute `simBlocked := simRunning || simUncertain`.
         - For each generated target:
           - If `xcodeBlocked`: apply `t.ReviewOnly = true`, `t.ReviewReason = domain.ReviewReasonActiveProcess`, `t.EligibleBytes = 0`, `t.TTLEligible = false`.
           - Else if `simBlocked && (isSimulatorTarget(t))`: apply `t.ReviewOnly = true`, `t.ReviewReason = domain.ReviewReasonActiveProcess`, `t.EligibleBytes = 0`, `t.TTLEligible = false`.
