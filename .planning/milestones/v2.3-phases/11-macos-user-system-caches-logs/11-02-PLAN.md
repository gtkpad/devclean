## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cleaner -> User Trash | Deletion of ~/.Trash contents must only happen with explicit flag authorization; root folder must never be removed |
| Cleaner -> External Mounts | Scanning must never follow or inspect /Volumes/*/.Trashes on external or network drives |
| Cleaner -> Shared Ecosystems | Exclusions prevent deleting caches owned by active language tools or package managers |
