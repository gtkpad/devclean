<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cleaner -> Active Running Processes | Deleting cache or state while an editor or CLI process is active can corrupt SQLite databases or in-flight data |
| Mutation Engine -> Virtual URIs | Deleting virtual URIs (editor://) via generic os.RemoveAll would fail or target unintended directories |
| Coordinator -> Filesystem During DryRun | DryRun must never mutate files, modify history, or stage items in trash |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-10 | Tampering / Race Condition | internal/cleaner/ai/ai.go:Clean | high | mitigate | Revalidate process state via checkProcessStatus immediately before unlinking in Clean(); abort if running |
| T-09-11 | Tampering / Unintended Execution | internal/cleaner/ai/ai.go:cleanEditorVirtualTarget | high | mitigate | Intercept editor:// URIs and delegate to surgical deletion helpers that touch only authorized leaf files |
| T-09-12 | Denial of Service / Collateral Review | internal/cleaner/ai/editors.go:scanEditors | medium | mitigate | Implement isolated Process Guard per editor: running Code only blocks Code targets; Cursor remains eligible |
| T-09-13 | Tampering / DryRun Mutation | internal/deleter/policy_test.go | high | mitigate | Validate zero-mutation invariant with cryptographic SHA-256 hashes and timestamp sentinels across all Phase 09 targets |
</threat_model>
