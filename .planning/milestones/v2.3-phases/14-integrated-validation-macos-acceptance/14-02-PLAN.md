<threat id="T-14-03" severity="high">
<description>
Bypassing ReviewOnly protection or deleting shared developer stores (pnpm global store, OrbStack container VM, active LaunchAgents, ScriptCache) through an alternate entry channel (e.g. CLI `--auto --yes`, headless TUI confirm, or MCP `execute_cleanup`).
</description>
<mitigation>
`cmd/workflow_v23_e2e_test.go` plants inviolable canary files in all review-only paths and programmatically exercises each of the 5 channels, asserting via `assertAllSentinelsIntact()` that sentinels remain 100% unmutated and untouched.
</mitigation>
</threat>

<threat id="T-14-04" severity="high">
<description>
Symlink traversal attacks or deletion of active application data during concurrent process execution, allowing attackers to trick cleaners into deleting `.git` repository histories, SSH keys (`~/.ssh`), or corrupting live browser caches.
</description>
<mitigation>
Fault-injection tests verify that `safety.IsCoreBlacklisted` and symlink validation block traversals outside target trees and that `Process Guard` flags targets as `ReviewOnly: true` with `ReviewReasonActiveProcess` whenever the mock executor reports the parent application process as running.
</mitigation>
</threat>
</threat_model>
