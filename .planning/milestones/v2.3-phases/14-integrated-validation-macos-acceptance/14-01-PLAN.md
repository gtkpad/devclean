<threat id="T-14-01" severity="high">
<description>
Arbitrary file deletion or host filesystem modification during unit test execution if tests fail to contain operations within `t.TempDir()` or if symlink traversal checks follow links pointing to user directories (`~/.ssh`, `~/.bashrc`, `/etc`).
</description>
<mitigation>
All unit tests strictly construct isolated trees inside `t.TempDir()`, pass mock command executors, and assert that symlinks pointing outside roots are rejected by `safety.IsCoreBlacklisted` and `isSafeSymlink` without file modification.
</mitigation>
</threat>

<threat id="T-14-02" severity="medium">
<description>
Silent coverage regression or introduction of dynamic CGO runtime dependencies escaping into production builds, causing failures on non-Darwin platforms or stripped environments.
</description>
<mitigation>
`scripts/verify-coverage.sh` enforces a hard `>= 85.0%` statement coverage floor per package with fail-fast non-zero exit codes, while `scripts/verify-builds.sh` enforces `CGO_ENABLED=0` across all 4 targets (`darwin/arm64`, `darwin/amd64`, `linux/amd64`, `linux/arm64`).
</mitigation>
</threat>
</threat_model>
