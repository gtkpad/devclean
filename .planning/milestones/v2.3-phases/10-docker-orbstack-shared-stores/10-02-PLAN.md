<objective>

Output: Refactored `internal/cleaner/docker/docker.go` and comprehensive hermetic unit test suite in `internal/cleaner/docker/docker_test.go`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cleaner -> Docker CLI | Invoking docker commands must prevent command injection via arbitrary arguments |
| Cleaner -> Filesystem Clean | Clean() method must never delete VM disks, daemon resources, or shared stores |
| Docker CLI -> JSON Parser | External stream output from docker system df may be malformed, truncated, or malicious |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-03 | Command Injection / Arbitrary Execution | internal/cleaner/docker/docker.go:Scan | high | mitigate | Pass arguments as discrete string slices to exec.Output without shell wrapper; never interpolate strings |
| T-10-04 | Denial of Service / Malformed Input | internal/cleaner/docker/docker.go:parseSystemDFOutput | medium | mitigate | Line-by-line unmarshaling with rawSystemDFEntry, flexible integer parsing, and partial degradation flag |
| T-10-05 | Tampering / Destructive Mutation | internal/cleaner/docker/docker.go:Clean | high | mitigate | Inviolable defensive guard immediately skipping ReviewOnly, docker://, and docker-vm-disk targets in Clean() |
</threat_model>
