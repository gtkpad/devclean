<objective>
Implement the OrbStack sub-scanner within the Docker cleaner ecosystem, strictly separating regenerable host caches from persistent VM/container data, applying sparse allocation accounting, and enforcing fail-closed Process Guard with pre-deletion revalidation (STORE-02, STORE-03, D-05, D-06, D-07, D-08, D-12).

Purpose: Fulfill requirements STORE-02 and STORE-03 by discovering OrbStack artifacts on macOS and Linux under the `"docker"` ecosystem, protecting persistent virtual machines and container images (`data.img.raw`) from deletion with `ReviewOnly: true` and honest sparse allocation reporting, while allowing safe cleanup of regenerable caches only when OrbStack is cleanly stopped.
Output: New `internal/cleaner/docker/orbstack.go`, updated `internal/cleaner/docker/docker.go`, and comprehensive hermetic unit tests in `internal/cleaner/docker/orbstack_test.go`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cleaner -> Host Process Table | Querying active processes via pgrep must not expose the application to command injection |
| Cleaner -> OrbStack Storage | Differentiating between disposable caches and persistent VM storage must be tamper-proof |
| Time-of-Scan -> Time-of-Clean | Process state changes between scan and deletion must not result in active container data corruption |
